# Task 規範目錄

本目錄作為 task file / Task Intake 主題的第二層索引。  
`AGENTS.md` 應只判斷是否進入本主題；具體流程與契約由本檔往下分流。

## 何時進入本目錄
- 使用者以「我要執行任務 {檔名/路徑}」啟動工作。
- 使用者使用 `/new` 或等價語意要求先導讀任務檔。
- 需求明確要求先整理任務內容、確認理解，再進入實作。

## 子文件索引
- `agent_governance/agent_docs/task_intake_workflow.md`
  定義導讀、澄清、確認、checklist 更新與 hard gate。
- `agent_governance/agent_docs/task_document_contract.md`
  定義任務檔的固定區塊、Immutable 原文與交接契約。

## 邊界
- 本目錄不取代 `progress_tracking.md`。
- 若只是一般聊天、檔案掃描或需求釐清，且尚未進入 task file 導讀，不必進入本目錄。
