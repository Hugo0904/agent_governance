# 進度紀錄機制 (Progress Tracking)

1. **任務啟動時**
   - 自動在 `progress/` 資料夾底下建立一個新檔案，檔名格式為 `任務代號.md`
   - 檔案必須由系統/Agent 自行生成，不得人工遺漏
   - 所有代理人都必須遵守，委託代理人也是

2. **任務過程中**
   - **必須更新進度筆記**，每完成一個步驟就立即更新
   - 更新方式為覆寫 `progress/任務代號.md`，保持最新狀態

3. **筆記格式**（範例）
   - **任務**
   - [x] 建立 API 架構
   - [] 撰寫單元測試
   - [] 整合部署流程

4. **規範要求**
   - [x] 代表已完成
   - [] 代表未完成
   - 所有步驟必須完整列出，避免遺漏
   - 筆記檔必須可供其他 Agent 或人員快速閱讀

5. **修改後的效果**
   - AGENTS.md 裡明確規範 **「progress/」是強制要求的紀錄機制**
   - 任何 Agent 在執行任務時，都必須同步產生與更新 `progress/xxx.md`
   - 進度筆記格式固定，利於機器與人類同步追蹤

6. **最近編輯前 20 索引（強制）**
   - 必須維護：`/Users/shawn/Code/progress/latest_20.md`
   - 內容僅保留最後編輯的 20 個進度檔（排除 `latest_20.md` 自己）
   - 每筆格式：`YYYY-MM-DD HH:MM | 檔名 | 一句摘要`
   - 每次新增或更新 `progress/*.md` 後，必須同步更新 `latest_20.md`
   - 當使用者 `/new` 後要回顧舊任務，先讀 `latest_20.md` 再開啟對應任務檔

7. **快速接手說明（建議固定在任務 md 開頭）**
   - 建議欄位：任務目標、功能範圍、主要檔案、關鍵規則、目前狀態、快速入口
   - 快速入口固定寫法：先看 `progress/latest_20.md` 再看本任務檔

8. **快速接手說明範例**
   - `**快速接手說明**`
   - `- 任務目標：...`
   - `- 功能範圍：...`
   - `- 主要檔案：...`
   - `- 關鍵規則：...`
   - `- 目前狀態：...`
   - `- 快速入口：先看 progress/latest_20.md 再看本檔`

9. **檔名規範（強制）**
   - `progress` 任務筆記檔名必須包含日期（`YYYYMMDD`）
   - 建議格式：`任務代號_YYYYMMDD.md`
   - 可接受範例：`s8_agent_group_games_exclude_closed_20260223.md`
   - 不可接受範例：`fix-release-datalock-for-locked-agent-users.md`

10. **清理規範（強制）**
   - 定期清理 `progress`：優先刪除 30 天前的任務 md
   - 清理後必須至少保留 30 筆任務 md
   - `latest_20.md` 為索引檔，不列入刪除目標
