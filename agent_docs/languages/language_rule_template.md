# <language> 語言規範

本檔用於整理 `<language>` 本身成立的穩定規則，不放單一專案、單一框架或單次任務特例。

## 適用範圍
- 本檔涵蓋哪些語言層級規則。
- 哪些內容仍應回到專案規則或框架文件。

## 穩定特性
- 整理語言語意、語法限制、標準函式庫行為或版本穩定特徵。

## 命名與風格
- 整理在該語言層級成立的命名原則、檔案拆分方式、常用寫法。

## 常見風險
- 整理 reviewer 常見會抓到的語言層級問題與反模式。

## 不放這裡
- 專案特有業務真相。
- 特定 framework 或框架版本限制。
- 只在單次任務成立的修正。
- 尚未被確認、仍停留在示例層級的說法。
